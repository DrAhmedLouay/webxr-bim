# WebXR BIM Advanced Platform

## Quick Start Guide

### For Desktop Users
1. Open https://drahmedlouay.github.io/webxr-bim/
2. Click "📂 استيراد نموذج (IFC/GLB)" to upload your BIM model
3. Use mouse to navigate: Left-click drag to rotate, Right-click drag to pan, Scroll to zoom
4. Click "🔍 كشف تلقائي للتعارضات" to detect clashes

### For VR Users (Meta Quest)
1. Put on your Meta Quest headset
2. Open Meta Quest Browser
3. Navigate to: https://drahmedlouay.github.io/webxr-bim/
4. Click the blue "ENTER VR" button at the bottom
5. Use controllers to interact with the model

## Technical Requirements

- Modern browser with WebGL 2.0 support
- For VR: Meta Quest 2/3/Pro or WebXR-compatible device
- Recommended: Chrome, Firefox, or Edge (latest versions)
- Minimum 4GB RAM

## Supported File Formats

- IFC (Industry Foundation Classes)
- GLB/GLTF (GL Transmission Format)
- More formats coming soon

## Troubleshooting

### Model won't load
- Check file size (max recommended: 100MB)
- Ensure file format is supported
- Try converting complex IFC to GLB first

### VR button says "NOT SUPPORTED"
- Normal on desktop computers
- Use Meta Quest Browser for VR functionality
- Ensure WebXR flag is enabled in browser

### Performance issues
- Reduce model complexity
- Close other browser tabs
- Use Level of Detail (LOD) versions
